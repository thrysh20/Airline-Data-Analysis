# Airline Data Analysis Dashboard

## Project Overview
This project focuses on analyzing airline data and presenting meaningful business insights through an interactive Power BI dashboard.

## Tools Used
- Power BI
- Power Query
- DAX

## Project Objectives
- Analyze airline performance.
- Identify booking trends.
- Understand passenger preferences.
- Compare performance across different categories.
- Identify important business insights.

## Key Features
- Interactive dashboard
- KPI cards
- Charts and visualizations
- Filters and slicers
- Data-driven insights

- Data Cleaning
- Data Transformation
- Data Visualization
- DAX Calculations
